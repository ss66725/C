## 运行测试

每个程序都有示例输入和期望输出（放在各文件夹的 `tests/` 里）。在仓库根目录运行下面的命令，会自动编译、运行并比对结果：

```bash
python run_tests.py
```

只检查某一天的程序，可以加上文件夹名：`python run_tests.py 261023`。

编译产生的 `.exe` 文件不纳入仓库，见 [.gitignore](.gitignore)。
