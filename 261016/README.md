# 261016 学习记录

今天是 C 语言入门，练习字符、浮点数和基本输入输出。

| 文件 | 内容 |
|---|---|
| 01.c | 对字符串 `"China"` 的每个字符加 4（字符按 ASCII 码运算），输出 `Glmre` |
| 02.c | 圆、球、圆柱的周长、面积、体积计算题，逐题输入答案并判断对错 |
| 03.c | 计算商品总价（单价 × 数量 × 折扣系数），总价不低于 80 时减 10 元 |

**知识点**：`char` 数组与字符运算、`float` 浮点数、`scanf` 读入、条件运算符 `?:`

**注意**：02.c 用 `==` 比较浮点数并不可靠。输入精确值时能通过，但输入四舍五入后的近似值（如用 `7.07` 代替 `7.065`）时会判错，之后可以改成比较误差范围。

**本次整理的改动**
- 01.c：`char a[5]` 改为 `char a[6]`，给字符串结尾的 `'\0'` 留出位置
- 03.c：提示语 `prince` 改为 `price`
