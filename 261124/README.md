# 261124 学习记录

今天复习指针，重点是把「返回指针的函数」和「调用方判空」这条链路理顺。

| 文件 | 内容 |
|---|---|
| 01.c | `find_max` 返回数组中最大元素的地址，调用方判 `NULL` 后再解引用 |
| 02.c | 用指针 `*(p + i)` 遍历一维数组 |
| 03.c | 用指针遍历字符串，数出字母个数（遇 `'\0'` 停止） |

**知识点**：返回指针的函数、`NULL` 作为「没找到」的约定、调用方必须先判空再解引用、指针算术 `p + i`、字符串以 `'\0'` 结尾

## 复盘：这题改了什么

第一版 `find_max` 有两个问题：

1. **没处理 `n <= 0`**：循环不执行，返回 `arr + 0`，是数组第一个元素的地址。数组是空的，这个地址看着合法，解引用读到的是垃圾值——比直接崩更危险，因为不报错
2. **调用方直接 `*find_max(arr, 5)`**：拿回来就解引用。一旦函数返回 `NULL` 就崩

改法是两边都补：函数里 `if(arr == NULL || n <= 0) return NULL;`，调用方 `if(p != NULL)` 才用。

这跟仓库里 `261110/malloc_average_max.c` 的错误是同一类：**拿到可能无效的指针，没能先判再用**。
