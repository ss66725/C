# 261116：链表

对应教材第 9 章 9.4.1–9.4.4（静态链表部分）。

## 文件

| 文件 | 内容 |
|---|---|
| `static_list_insert.c` | 静态链表：三个节点手动连成链、遍历输出、在中间插入一个节点 |

## 知识点

- **节点**就是链表里的一个元素，也就是一个结构体变量。
- 链表的结构体里必须有一个指向自身类型的指针成员 `struct student *next`。写成 `struct student next;` 不行：结构体里装自己会无限嵌套，`sizeof` 算不出来。
- 链表的末尾节点 `next` 必须置为 `NULL`，遍历靠 `while (p != NULL)` 或 `for (; p != NULL; p = p->next)` 结束，不能用下标。数组可以按下标走，链表没有下标。
- 遍历三要素：从 `head` 出发、读数据、`p = p->next` 前进。
- `p->name` 和 `(*p).name` 等价；`p` 是指针，所以用 `->`。
- **插入节点只改两条 `next`**，被插入位置后面的节点一个字都不用动。
- **先接后断**：先写 `新节点->next = 原后继`，再写 `前驱->next = 新节点`。反了会先把后面的链子丢掉。
- 静态链表里节点是有名字的变量（`s1`、`s2`），丢掉的地址还能通过名字拿回来；动态链表里节点没有名字，接错就真的找不回来，所以这个顺序在动态链表里是必须遵守的。
- 结构体类型定义要放在所有函数外面，否则 `main` 外的函数看不见这个类型，会报 `incomplete type`。
