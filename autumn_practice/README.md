# autumn_practice 秋季练习

这一组练习不按日期整理，而是按题号排列，覆盖了基础语法到递归的内容。

| 题号 | 文件 | 内容 |
|---|---|---|
| 01 | hello_world.c | 输出 `hello world` |
| 03 | basic_io.c | 基本输入输出和运算：整数与浮点数求和，计算 1–100 的和 |
| 04 | reverse_array.c | 数组逆序（1–9 倒过来输出） |
| 05 | score_average.c | 二维数组：求所有成绩的平均分、查询某位同学的成绩、列出不及格（≤ 4 分）的同学 |
| 06 | 06number_guessing_game.c | 猜数字游戏：1–100 之间，7 次机会，可以重新开始 |
| 07 | sort_three.c | 输入三个数，用指针和交换函数按从大到小排序 |
| 08 | string_copy_pointer.c | 字符串复制（指针写法的代码已注释，保留作参考） |
| 09 | recursive_age.c | 递归：第 1 个学生 10 岁，之后每人比前一人大 2 岁，求第 n 人的年龄 |
| 10 | factorial_recursive.c | 递归求阶乘 |
| 11 | hanoi.c | 汉诺塔：输出 n 个圆盘的移动步骤 |

**知识点**：输入输出格式、数组与二维数组、指针与函数参数、递归、汉诺塔的递归思路

**本次整理的改动**
- score_average.c：`search` 增加了编号范围检查（1–3），原来输入越界编号会访问无效内存。同时给成绩输出之间加了空格，原来数字会连在一起

## 期望输出

本文件夹里的程序都有期望输出，放在 [tests/](tests/) 文件夹中。在仓库根目录运行 `python run_tests.py autumn_practice` 即可自动检查。
