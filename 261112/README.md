## 知识点

- 结构体类型声明放在函数外，整个文件都能用；放在 `main` 里面，出了 `main` 就没了。
- 先声明后使用：函数定义写在 `main` 后面时，前面要放原型。
- `struct student stus[3]` 是按同一个类型创建 3 个变量，不是往一个变量里放 3 个学生。`sizeof` 为 28 和 28 × 3 = 84。
- `name` 是字符数组，赋值必须用 `strcpy`；`age`、`grade` 是 `int`，直接 `=`。
- `p->age` 等价于 `(*p).age`。`.` 的优先级高于 `*`，所以括号不能省。
- `s[i]` 已经是结构体本身，后面用 `.`；`(s + i)` 是指针，后面用 `->`。等价写法：`s[i].age` 与 `(s + i)->age`。
- 指针加减按指向类型的大小算：`p++` 前进 28 字节（`sizeof(struct student)`），不是 1 字节。
- 结构体变量作参数是值传递，整个结构体被拷贝一份，函数里改了不影响外面；指针作参数才能改动本体。
- 找最值时比较的必须是当前最大值 `max->age`，不能固定用 `s[0]`。反例：年龄为 {21, 40, 30} 时，写成 `> s[0]` 会返回 Tony。
